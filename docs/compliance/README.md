# Compliance and governance pack

This folder is the working home for policy and control artifacts required for a regulated financial product.

## Minimum baseline

- privacy notice
- merchant agreement and terms
- AML/KYC policy
- risk and sanctions screening controls
- incident response procedure
- data retention and deletion policy
- audit and approval matrix
- admin access control policy

## Operational requirement

All major platform changes should cross-check this folder before production rollout. The backend enforces code-level security constraints, but operational controls remain essential for real-world financial compliance.
