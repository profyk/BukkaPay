# Merchant App

The merchant app is a separate operational experience for businesses, agents, and payout workflows.

Core areas:

- merchant onboarding and KYC state
- payout and settlement visibility
- customer-to-merchant transaction history
- refund and dispute operations
- risk review and account status management

The merchant app should share the same backend contracts as the customer app but use a different navigation model, user roles, and security posture.
